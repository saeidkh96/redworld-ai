# v1.2.4 — Real-Time Viewer & Smooth Motion

RedWorld AI v1.2.4 improves the live Genesis City viewer without changing the
authoritative simulation model or reducing world scale.

## Viewer performance

This release removes several frontend bottlenecks that caused the visual world
to feel slower than the optimized simulation backend.

Key improvements include:

- active rendering target increased from 24 FPS to 60 FPS
- static city geometry is no longer rebuilt on every simulated minute update
- zoom uses compositor-based preview during interaction
- expensive static rendering is committed only after zoom gestures finish
- geography lookup work uses cached indexes instead of repeated linear scans
- unnecessary per-frame allocations were reduced

## Smooth citizen motion

Citizen movement now interpolates from each agent's current visual position
rather than restarting from the previous authoritative location.

The motion system now includes:

- smoother interpolation curves
- continuous retargeting
- distance-aware transition duration
- improved cinematic route interpolation
- reduced visible snapping between simulation updates

## Live viewer metrics

The viewer metric previously labeled `WS latency` has been corrected to
`WS age`.

It represents the elapsed time since the most recent WebSocket update, not
network transport latency.

## Runtime architecture

The backend remains authoritative.

The viewer renders and interpolates simulation snapshots independently of the
browser frame rate. The existing WebSocket cadence remains unchanged in this
release so simulation speed is not unintentionally altered.

## Preserved scale and behavior

v1.2.4 preserves the validated world scale and systems from v1.2.3:

- 1,500 citizens
- 40 businesses
- 4 civic institutions
- 1,544 autonomous agents
- deterministic simulation behavior
- accounting and economy
- physical movement
- social interaction
- autonomous agent reasoning
- Human-in-the-Loop review

No simulation population reduction or backend simplification was introduced.
