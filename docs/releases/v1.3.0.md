# RedWorld AI v1.3.0 — Emergent Living World

v1.3.0 integrates entity-level demography, employment/business mutation, policy effects, physical city development, crises, and migration into the simulation lifecycle.

The key architectural change is that civilization outputs can now become durable world-state changes instead of remaining aggregate counters. The evolution service is deterministic, bounded, event-emitting, and idempotent at monthly/yearly boundaries.

## Runtime integration

- Annual: life events mutate citizens and households.
- Monthly: employment/businesses, policy effects, city development, crises, and migration mutate real entities.
- Autonomous agent bootstrap continues to discover newly created citizens/businesses.
- `GET /api/v1/world/evolution` exposes realized mutations and active shocks.
- World summary reports `version: 1.3.0` and `world_evolution` metrics.

## Safety and performance

Mutation volume is deliberately bounded per month/year to avoid large tick spikes. Existing Human-in-the-Loop review remains the authority for high-risk autonomous-agent proposals; this release does not bypass that review path.
