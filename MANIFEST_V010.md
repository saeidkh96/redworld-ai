# RedWorld AI v0.1.0 Upgrade Manifest

This package upgrades the v0.0.1 foundation through the complete v0.1.0 First Closed Economy line.

## Major additions
- `src/redworld/domains/accounting/` — double-entry ledger, accounts, postings, journal invariants
- `src/redworld/domains/employment/` — contracts, hiring and payroll
- `src/redworld/domains/businesses/` — production, inventory, sales and profit calculation
- `src/redworld/domains/banking/` — deposits, reserve-backed lending, interest, schedules, balance sheet
- `src/redworld/domains/government/` — income/business tax, treasury and welfare
- `src/redworld/domains/economy/` — derived economy metrics
- event history and modular world orchestration
- expanded API summary
- official RedWorld AI logo under `assets/branding/`
- release notes and PowerShell validation script

## Version
`0.1.0`
